Built for reading, not for decoration.

Yore is a simple yet feature-rich Hugo theme, designed specifically for content-heavy blogs, placing textual clarity first. Despite its simplicity, Yore offers multiple layouts, headers, and customization options.

## Features {#features}

- **Content delivering**

  17:1 text contrast, far exceeding WCAG-AAA's 7:1 minimum. Content works the same whether it's multilingual, versioned, part of a series, or read right to left. Every component follows authoritative accessibility guidelines, with built-in keyboard focus and screen-reader friendly markup. A standalone accessibility control panel lets readers adjust the site to their own needs.

- **Layout**

  Pick from 3 header options and 2 hero styles, built on a 3-layered CSS structure that keeps overrides predictable. The same foundation covers blog, documentation, and gallery layouts without fighting the theme.

- **Under the hood**

  Components are built on modern browser APIs, which means less JavaScript and better accessibility by default. Pages switch smoothly through [swup.js](https://swup.js.org/) client-side routing, without distracting transition animations. It stays friendly to older devices too, and the site browses perfectly well even on a 10-year-old iPhone 8.

- **Shipping it**

  Perfect Lighthouse scores on desktop and mobile, an A+ rating on [HTTP Observatory](https://developer.mozilla.org/en-US/observatory/analyze?host=yore.zsl0621.cc), and a GDPR cookie consent banner out of the box. Images resize themselves, so nothing needs manual tuning before launch. A 4000-page documentation site [builds in 16 seconds](../960-benchmark/index.md).
