為閱讀而生，不為裝飾。

Yore 是一款簡單卻功能豐富的 Hugo 主題，專為大量內容的部落格設計，以文字清晰為第一優先。雖然簡單，Yore 仍提供多種版面、標頭與客製化選項。

## 特色 {#features}

- **內容呈現**

  文字對比度達 17:1，遠超 WCAG-AAA 要求的 7:1 下限。無論是多語系、多版本、系列文章，還是由右至左閱讀，內容呈現都一致。每個元件都遵循權威的無障礙指引，內建鍵盤焦點與對螢幕朗讀軟體友善的標記。獨立的無障礙控制面板讓讀者能依自身需求調整網站。

- **版面**

  可從 3 種標頭與 2 種主視覺樣式中選擇，並建立在 3 層 CSS 結構上，讓樣式覆寫保持可預期。同一套基礎涵蓋部落格、文件與圖庫版面，不必與主題對抗。

- **底層實作**

  元件建立在現代瀏覽器 API 之上，代表預設就有更少的 JavaScript 與更好的無障礙表現。頁面透過 [swup.js](https://swup.js.org/) client-side routing 順暢切換頁面，沒有干擾視線的轉場動畫。對舊裝置也很友善，即使是 10 年前的 iPhone 8 也能順暢瀏覽。

- **上線發布**

  桌面版與行動版 Lighthouse 皆為滿分，在 [HTTP Observatory](https://developer.mozilla.org/en-US/observatory/analyze?host=yore.zsl0621.cc) 取得 A+ 評級，並內建符合 GDPR 的 Cookie 同意橫幅。圖片會自動調整大小，上線前不必手動調校。文件可匯出成單一 PDF 檔案，包含目錄與可運作的內部連結。擁有 4000 頁的文件網站[只需 16 秒即可建置完成](../960-benchmark/index.md)。
