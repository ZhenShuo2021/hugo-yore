{{- /* Computes the base path and content hash for an image, used to build cache-busted output filenames. See render-hook.html for usage example. @param imgObj {resource.Resources}: The image resource. @returns {map} A dict with `base` (path without extension) and `hash` (6-char xxhash of the decoded path). */ -}} {{- $imgObj := . -}} {{- $decodedPath := urls.PathUnescape $imgObj.RelPermalink -}} {{- $base := path.Join (path.Dir $decodedPath) (path.BaseName $decodedPath) -}} {{- $hash := substr (hash.XxHash $decodedPath) 0 6 -}} {{- return (dict "base" $base "hash" $hash) -}}
